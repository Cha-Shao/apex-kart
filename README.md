# APEX · 卡丁车实验室

用 Vite、TypeScript、Three.js 和 cannon-es 构建的 3D 卡丁车小游戏。

所有赛道共用可调水位：在「地形高度层 → 水面」开关水面、设置水位，地形低于该高度时形成水域，岸线随高度笔刷自动变化。手绘地形默认水位 -1 m；真实赛道保留 DEM 的起点高程基准，用它换算近似海平面，紧凑版同步等比缩放。水位和关闭状态随赛道保存、导入和导出。完整地形继续支撑路面与缓冲区，水面通过深度遮挡与陆地相交；植被和环境设施避开水域。水面采用 PBR 天空反射与动态细波纹。来源及高程精度说明见 `public/circuit-credits.html`。

地形、水面、岸线和临水路基统一从全局规则生成，不按赛道 ID 打补丁，也不单独修改赛道数据修图（协作约束见 `AGENTS.md`）。生成时合并地形格网尺度的狭窄干燥草堤、收窄水边过宽的道路平整区；路面、路肩、缓冲区及护栏外支撑带保持连续地基，挡岸和检修边沿同一铺装边界生成。渲染与碰撞使用同一份派生地形，原始高度笔刷和保存数据保留；手绘和真实赛道共用此流程。水波使用两层漂移噪声法线及 mipmap，避免规则平行条纹；挡岸为可视网格，不新增碰撞体。


## 游戏

- `W / ↑`：油门；`S / ↓`：刹车，停稳后倒车。
- `A D / ← →`：转向；`Space`：后轮手刹。
- `R`：在最近赛道路段复位，并重置本圈计时。
- `C`：切换跟随、俯视、座舱和环绕视角。
- `Esc`：暂停 / 继续；切到其他窗口时自动暂停。
- 手机和平板支持触屏转向及油门、刹车踏板。
- 引擎音效默认关闭，可从顶栏开启。

## 手绘赛道

1. 点击画笔按钮，在画布上画一条不自交的环线；松手后自动闭合。
2. 原始笔画经等距去重和 RDP 简化，再经闭合 Chaikin 与向心 Catmull–Rom 样条生成平滑中心线。
3. 以约 1.6 米间隔采样曲线，以有符号曲率区分直道、缓弯和急弯。
4. 自动生成路面、白色边线、弯道红白路肩和可选的物理碰撞护栏。
5. 用控制点工具拖动调整路线并配置路宽；曲线平滑度默认为 50%。

编辑器会拒绝自交、短环线和间距不足的路段。手绘坐标映射为世界坐标，单位为米。赛道保存于当前浏览器的 localStorage；支持 JSON 导入 / 导出，无服务端存储。

## 物理实现与范围

- cannon-es 动态刚体、地面和沿赛道布置的静态碰撞体。
- 120 Hz 固定物理步长，独立于渲染刷新率。
- 四轮射线悬挂：弹簧、压缩和回弹阻尼、低重心车身。
- 后轮驱动、速度相关驱动力、Ackermann 前轮转向、高速转向限幅。
- 轮胎侧向和纵向摩擦、滑移限幅、后轮手刹、草地抓地衰减。
- 二次空气阻力、滚动阻力和实际碰撞响应。
- 顺序检查点与起终点越线判定，记录本地最佳圈速。

这是使用真实刚体物理引擎的可玩原型。车辆和轮胎参数未经实车标定，不能视作专业车辆动力学仿真；路肩目前是视觉网格，尚无独立凸起碰撞体。赛道为平面闭合环线，不支持桥梁、交叉和高低差。

## 文件

- `src/track.ts`：输入校验、平滑、曲率分析、最近路段与 JSON 交换。
- `src/editor.ts`：支持鼠标和触摸的绘图画布、控制点、撤销。
- `src/physics.ts`：物理世界和车辆控制。
- `src/scene.ts`：3D 赛道、环境、相机和轮胎痕迹。
- `src/kart.ts`：项目内生成的卡丁车和驾驶员模型，支持车身换色。
- `src/main.tsx`：应用界面、练习计时、键盘和触屏交互。
- `tests/`：赛道几何和物理行为测试。

`scripts/browser-check.mjs` 是此开发环境使用的浏览器验收脚本，引用了本机已安装的 Playwright 和 Chrome。其他机器需要调整其中的运行时路径。

字体来自 Google Fonts，加载失败时使用本机字体；所有游戏模型、材质、场景和图标已包含在本地包中。

## 驾驶修正

制动按120Hz物理步长把0.85g目标减速度换算为每轮冲量，前后分配54:46并渐进施加；重心下降20厘米，视觉车身和轮胎位置保持一致。倒计时使用静态起跑保持，GO同一帧释放并读取已按住的油门；跟随镜头直接切入起跑位置。路肩宽度由0.94米增至1.88米。沥青缓冲区由进一步平滑的中心线生成，仅在弯道外侧出现，进入和离开弯道时渐收；其可视四边形也用于抓地范围判定，直道和内弯保留草地。

路肩改为随路面地形延伸的平面，保留红白涂装、宽度和出弯延长段，移除独立凸起碰撞网格；桥面碰撞范围包含平面路肩。压路肩音效复用逐轮白线判定中的接触位置，按胎面覆盖程度触发左右声道的低频撞击与砂砾噪声，车速控制节奏与强度，驶入/驶出平滑过渡。低于 2 km/h、悬空、未压到路肩时不会持续发声，暂停/静音时淡出，与顶栏声音开关同步。两车型均支持，不施加额外振动力或相机抖动；本次仅编译，未跑测试。

采样预算改为控制点数量的三倍，最少 160、最多 1600，保持等弧长用于圈速和分段索引，不再因 1:1 的米制长度增加采样数量。缓冲区的完整外移量采用五次曲线渐收，入口约为宽度 2.5 倍距离、出口约为 3.5 倍，遇到反向弯提前收回；左右侧分别生成避免切边。过渡段接在实际路肩外缘，没有路肩处接回路面。抓地判定复用车身最近路段结果。仅编译，未进行帧率或驾驶测试。

赛道附属设施按米制尺寸计算：弯外缓冲区会随入弯前连续直线长度、弯曲程度和布局尺寸增大，并扩大平滑窗口；直道与弯内保留草地。外侧路肩在出弯后延伸约 14–70 米并渐收，内侧不增加尾段，视觉和轮胎碰撞共用几何。弯前距离牌按可用直线长度布置，长布局为 150/100/50 m，短布局为 75/50/25 m；为游戏生成位置，并非实地逐牌测绘。移除页面底部 footer、LIVE VIEW 和 FREE PRACTICE 卡片。高程暂缓，未改动任何地形高度。

新增逐轮自动 ABS 辅助（两车默认启用）：在每个 120 Hz 物理步的悬挂求解之后，按轮胎当前载荷分配制动，并为转向保留摩擦圆余量；立即泄压、渐进恢复。该射线轮胎模型没有独立轮胎惯量，ABS 使用载荷与摩擦需求，不读取 Cannon 刹车时被强制归零的轮速。卡丁车目标制动从 0.85g 提高至 1.45g；RB20 低速目标 2.4g，随实际下压力增大至最高 6g，最终均受每轮地面抓地限制；同时踩油门和刹车时制动优先。原有低重心保持。

驾驶输入新增踏板虚线、实际制动实线、两者间的削减阴影及 ABS 状态。RB20 方向盘显示实时档位，上方为 13 颗绿/红/青转速灯，在 6500–11600 rpm 渐进点亮。V6 合成音降低涡轮啸叫与高次谐波，增加低频并柔化高频。ABS 属于本游戏驾驶辅助，不代表实车配置。此次按要求只编译，没有运行测试或上传。

新增可切换的 2024 Red Bull RB20（维斯塔潘最近一次车手冠军用车），选择器使用 React TSX。以公开的 798 kg 最低质量、1.6 升 V6 涡轮混动、15,000 rpm 和八挡变速箱为基础，独立配置轮距、悬挂、低重心、制动、速度相关下压力与空气阻力。传动比与空气动力参数为游戏近似；没有完整 ERS 能量管理。车长约 5.6 m、车宽约 2 m，不沿用卡丁车缩放。座舱可见实体 Halo 环、中央支柱、方向盘及前轮；隐藏头盔时保留 Halo。音效随车型切换为原创 V6 合成声。车型选择保存在本地，RB20 最佳圈速与卡丁车分开记录。来源与近似范围见 public/vehicle-credits.html。

车辆模型、物理轮距、轴距、碰撞体共用src/kart-spec.ts中的米制规格。外廓调整到约1.35米宽、1.8米长，轮胎直径0.28米、轴距约1.22米；悬挂行程与起跑静态高度同步缩短，保留165kg整车与驾驶员合计质量及渐进制动。6米路宽下车宽约占22.5%。

## TSX 圈速卡片

入口为src/main.tsx，圈速卡片使用React TSX（src/components/LapTimes.tsx）。当前圈速并入卡片顶部，不显示标题。最近10圈通过grid对齐圈号、成绩与三段时间；仅列表最快圈显示完整时间，其余显示相对该圈的+秒差。最快圈右侧悬浮紫色计时徽章，四轮完全越过白线的圈右侧悬浮红色叹号；二者可同时出现。

白线判定每个120Hz物理步检查四个轮胎，计入胎宽对白线的重叠，且独立于沥青缓冲区的抓地判定。出界标记在该圈锁存，过线时写入成绩。

## 风格化写实与环境层次

保持晴天 HDR 与太阳方位一致，降低均匀环境补光占比，补充车辆下方随地面法线变化的轻量接触阴影。草地将原有草叶法线与程序生成的厘米级草簇高度场法线叠加，配合草簇凹处轻微压暗、粗糙度变化和适度日光反射，补足驾驶距离下的表面起伏；共享贴图使用 mipmap 和各向异性过滤。另保留数米草簇色差、数十米绿色变化及柔和割草方向。沥青保留无裂缝细粒底图，增加骨料凹凸、局部修补色差与轻微橡胶使用痕迹，动态打滑痕迹继续保留。

路肩仍为连续网格：沿赛道的自定义 UV 在材质中产生约 54 厘米分块、浅接缝、横向倾斜的法线观感、边缘磨损与污渍。没有逐块砖模型，没有新增路肩高度或碰撞。布置采用统一弯道规则：弯中只铺内侧，外侧仅在入弯前和出弯后出现。外侧前段按布局尺度延伸约 24–120 米、后段约 32–160 米，并受可用直线长度限制；同侧间隔不超过约 12–60 米的路肩在直线段合并，仅在合并后整段的端部渐收，弯中外侧保持留空。连续同向弯之间的短暂平缓段不插入外侧路肩，真实赛道与手绘赛道共用。

植被按群落分布，结合树形/高度变化、复用 CC0 树叶的灌木与近景少量草叶；增加柔化泥土边界、分段视觉护栏、轮胎墙、广告牌与排水条。已移除散布房屋、孤立的沥青维修直线及路肩外侧青色装饰条，保留原维修区与看台。设施为程序化氛围布置，不代表真实赛车场逐项测绘，也不增加物理障碍。重复物件使用 GPU 实例化，树木继续使用 LOD，草叶、灌木和轮胎墙按距离裁剪，未加入全场实时 GI 或光线追踪。

赛道表面采用统一高度和深度预处理，按「黑沥青 > 白线 > 路肩 > 浅灰缓冲区」合成。黑沥青保留本路段白线槽位；其他路段黑沥青可以覆盖冲突的白线与路肩。路肩按赛道生成顺序覆盖，后段覆盖前段，避免自交处深度闪烁。立交、车辆与场景物体继续按真实空间深度遮挡，驾驶物理不变。

照明为固定晴天 HDR 预设，太阳高度约 48°，未绑定地理位置、日期或真实钟点。太阳直射之外，保留 HDR 天空环境、天空/地面半球补光与少量中性环境光，让背光面仍有材质层次；驾驶模式的黑色渐变已减弱。透明叠加明确按地面装饰、接触阴影、胎印、烟雾的顺序合成，烟雾保留正常深度测试，车辆和地形仍能遮挡烟雾。
